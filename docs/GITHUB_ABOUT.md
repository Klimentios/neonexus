## First GitHub Release

**Tag:** `v1.0.0` (create only after confirming the intended commit)

**Title:** NEONEXUS 1.0.0

**Body:**

NEONEXUS brings AI agent CLIs, optional API models, and local models into one local room. Version
1.0.0 includes team chat, live agent terminals, evidence-based projects, Code mode with builder and
reviewer, an embedded code-server editor, 12 UI languages, and loopback-only room services.

macOS installation was tested from a fresh clone. Linux and Windows installers have syntax/parser
checks only and need on-device verification. Real-microphone voice use and a sustained joint
Claude–Codex–Gemini session are also unverified.

See `CHANGELOG.md` for details and `INSTALL.md` to get started.
NEONEXUS is AGPL-3.0-or-later and is based on agentchattr by Ben Curtis (MIT); see NOTICE.md.
